# WhatsApp Webhook Integration

## Required Configuration

- Tenant-specific webhook URL
- Subscription to message:new event

## Setup

1. Open Settings > Integrations > WhatsApp.
2. Copy your webhook URL.
3. Paste it in your WhatsApp provider webhook configuration.
4. Subscribe to message:new.
5. Click I have connected.

## Validation

:::tip

- WhatsApp status changes to Connected.
- Chats load in WhatsApp section.
- New inbound and outbound messages appear.

:::
